# Aufrichten

Eine ruhige, mobile Tagesroutine mit sechs Übungen für mehr Haltungsbewusstsein. Die Anwendung ist für die Nutzung in Safari auf dem iPhone optimiert und speichert Fortschritte ausschließlich lokal im Browser.

## Nutzung

Die App besteht aus statischen Dateien und benötigt keinen Build-Schritt. Lokal kann `index.html` direkt geöffnet oder über einen einfachen Webserver bereitgestellt werden.

Auf dem iPhone lässt sie sich in Safari über **Teilen → Zum Home-Bildschirm** wie eine App ablegen.

## Datenschutz

Es gibt kein Benutzerkonto und kein Backend. Übungsfortschritte werden nur über `localStorage` auf dem jeweiligen Gerät gespeichert.

## Gesundheitlicher Hinweis

Die Inhalte sind eine allgemeine Bewegungshilfe und ersetzen keine medizinische oder physiotherapeutische Beratung. Bei Schmerzen, Taubheit, Schwindel oder anhaltenden Beschwerden sollte die Routine pausiert und fachlicher Rat eingeholt werden.
